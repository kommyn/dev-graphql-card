# Dev Card

GraphQL API визитки разработчика: профиль, места работы, проекты и навыки.

**Стек:** NestJS 11, GraphQL (Apollo, code-first), Prisma 7, PostgreSQL 16.

## Запуск через Docker

Порядок запуска через Docker:

```bash
cp .env.example .env
docker compose up --build
```

API поднимется на **http://localhost:3000/graphql** и там же открывается GraphiQL для запросов.

При старте контейнер сам накатывает миграции и заполняет базу тестовыми данными, так что после `up` API сразу готов к запросам.

## Переменные окружения

Располагаются в `.env`. Для быстрого старта достатчно скопировать `.env.example` в `.env`.

| Переменная | Описание |
|---|---|
| `DB_URL` | строка подключения, её использует приложение |
| `DB_USERNAME`, `DB_PASSWORD`, `DB_DATABASE` | этими значениями Compose инициализирует Postgres |

Значения в `DB_URL` и в остальных переменных должны совпадать, иначе приложение не пройдёт аутентификацию. Хост в `DB_URL` - `dev-card-db`: это имя контейнера базы во внутренней сети Compose.
